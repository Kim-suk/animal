# 🥚계란 고냥이🐈
KG아이티뱅크에서 주간하는 Spring Framework를 사용해서 만든 웹 사이트입니다. Spring Framework 3.1.1.RELEASE을 사용했습니다.

'반려묘/견'을 키우는 사람들과 고민중인 사람들을 위한 정보 제공 사이트를 제작해봤습니다.

## 🗂️ 프로젝트 소개 🗂️
- 반려묘/견을 키우는 사람들과 고민중인사람들을 위한 정보 제공 사이트입니다. 단순히 정보제공사이트가 아닌 Kakao Map을 통해서 '내 위치' 기반으로 반경 1km에 있는 동물 병원 위치도 '마커'를 통해서 지도로 한 눈에 확인할 수 있습니다.

- 강아지,고양이,자유,병원후기 게시판을 통해서 많은 사람들이 해당하는 게시글을 작성할 수 있으며, 많은 사람들이 게시글을 통해서 **'정보 공유'** 할 수 있는 시스템을 구축하였습니다.

- 반료묘/견을 키우는 사람들위한 정보 제공 페이지도 마련되어 있습니다. 또한 반료묘/견을 키우려고 고민중인 사람들을 위해서 반료묘/견을 키우기 위해서 어떤 준비를 해야하고, 어떤 견종/묘종이 있는지 그리고 필수케어 가이드 등 **다양한 정보들을 제공해주는 페이지**들을 구성했습니다.

- 우리 아이들을 위해서 필요한 다양한 '용품'들을 준비했습니다. 예를들어서, 사료, 장난감, 간식, 배변용품, 하우스 등등 다양한 우리 아이들에게 필요한 물품들을 구매할 수 있는 **'상품 페이지'** 를 마지막으로 구성해봤습니다.
